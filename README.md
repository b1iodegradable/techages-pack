## 📖 О сборке

Вы начинаете с кремнёвых инструментов и шаг за шагом открываете новые эпохи. Каждую эпоху открывает
одна большая цель: машина или босс. Новые моды, руды и измерения становятся доступны только после неё.

| | Эпоха | Что открывается |
|---|---|---|
| 🪨 | **0. Первобытная** | выживание, первые инструменты и убежище |
| ⚙️ | **1. Кинетическая** | Create: валы, шестерни, первые механизмы |
| 💨 | **2. Паровая** | паровые двигатели, дирижабли, Незер, карта мира |
| ⚡ | **3. Электрическая** | электричество, сталь и нефть (TFMG), джетпак |
| 🏭 | **4. Индустриальная** | Mekanism, хранилище AE2, быстрые перемещения |
| ☢️ | **5. Высокие технологии** | реактор деления, магия на службе техники |
| 🚀 | **6. Космическая** | ракеты Northstar, высадка на Луну |
| ⭐ | **7. Эндгейм** | Звезда Инженера, творческие предметы, финальный босс на Луне |

**Ещё в сборке:** боссы Cataclysm и Mowzie's Mobs (с «пробуждёнными» версиями), магия (Ars Nouveau,
Iron's Spellbooks, Occultism, Malum, Astral Sorcery), торнадо, сезоны, серверная экономика с аукционом,
ивенты и соревнования, квесты FTB Quests (кнопка в инвентаре) и экран достижений **L** в стиле SevTech.

Основной путь до космоса — около 80–100 часов, дальше несколько месяцев эндгейма.
Внутри игры есть «Справочник инженера»: кнопка-книжка слева сверху в инвентаре.

## 🛠️ Установка

> Нужно: лицензия Minecraft (аккаунт Microsoft), **16 ГБ ОЗУ** на ПК (минимум 12), ~3 ГБ на диске.

1. **Установи [Prism Launcher](https://prismlauncher.org/download)** и войди в аккаунт Microsoft
   (справа вверху → «Аккаунты» → «Добавить Microsoft»).
2. **Скачай [TechAges-prism.zip](https://github.com/b1iodegradable/techages-pack/releases/latest/download/TechAges-prism.zip)**.
   Распаковывать не нужно.
3. В Prism: **«Добавить сборку»** → слева **«Импорт»** → выбери скачанный zip → **ОК**.
4. Нажми **«Играть»**. Сначала появится окошко **packwiz**: оно скачивает моды, конфиги и квесты
   (в первый раз несколько минут). Потом Prism докачает Minecraft и NeoForge. Если спросит про Java,
   соглашайся скачать Java 21.
5. Первый запуск игры долгий (2–4 минуты), это нормально.
6. **Сетевая игра** → **Добавить** → адрес сервера, который дал админ.

<details>
<summary><b>💾 Память</b> — если на ПК 12 ГБ</summary>

В сборке уже выставлено 8 ГБ. На ПК с 12 ГБ поставь 6144: правый клик по сборке → **«Изменить»** →
**«Настройки»** → **«Java»** → «Максимум». Больше половины ОЗУ ПК не ставь.
</details>

## 🔄 Обновления

Делать ничего не нужно. При каждом запуске packwiz сверяется с этим репозиторием и докачивает
**только изменённые файлы**. Если админ написал «вышло обновление», просто перезапусти игру.

> ⚠️ Не трогай «Изменить» → «Настройки» → «Пользовательские команды»: там команда автообновления.
> Свои моды тоже не добавляй: сервер пускает только с точным набором модов.

## ❓ Если что-то не так

| Проблема | Что делать |
|---|---|
| packwiz пишет ошибку / нет интернета | Нажми «Continue»: игра запустится с прошлой версией. На сервер со старой версией может не пустить. |
| packwiz просит скачать мод вручную | Открой ссылку из окна, скачай файл, положи куда скажет. Напиши админу название мода. |
| «Mod mismatch» при входе на сервер | Перезапусти игру, чтобы packwiz докачал обновление. |
| «You are not white-listed» | Напиши админу свой ник. |
| Вылет при запуске / «Out of memory» | Прибавь память (см. «Память» выше). |
| Мало FPS | Дальность прорисовки 8–10. Шейдеров нет: Iris несовместим с текущим Sodium. |
| Что-то другое | Скинь админу `logs/latest.log` (в Prism: правый клик по сборке → «Папка»). |
